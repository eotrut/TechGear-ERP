# Permission matrix

> Generated by `npm run gen:permissions` from `src/lib/rbac/matrix.ts`.
> Do not edit by hand: the matrix module is the source of truth and this file
> is regenerated from it, so any edit here would be silently overwritten.

`Y` full access, `own` limited to records the user owns or created, `-` denied.

Enforced at three layers:

1. `src/middleware.ts` gates navigation against the JWT (fast, and stale by up to the token lifetime).
2. `requirePermission()` in every protected page, re-reading the live user record.
3. `authorizeAction()` / `authorizeRecord()` in every server action and route handler.

The UI hides what a role cannot do, but hiding is never the control.
